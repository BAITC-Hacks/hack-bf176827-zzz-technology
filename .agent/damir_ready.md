# Готовность части Дамира

Обновлено: 23 сентября 2026. План: [damir.md](damir.md).

**Изменение по прямому указанию Дамира:** основной интерфейс написан на React
в отдельной папке `frontend/`; Docker Compose запускает сервисы `app` и
`frontend`. Это заменяет требования исходного плана про HTML без фреймворков
и один сервис Compose. Остальные требования сохранены.

## D0 — скелет, валидатор, команды

- **Готово:** локальный Cytoscape, мок 10 узлов / 12 рёбер.
  Резервный просмотрщик сохранён в `web/`; React-мок открывается через `?demo=1`.
- **Готово:** `cmd/check` проверяет три CSV; ошибки по файлу/строке,
  exit 1 при нарушениях, сводка ролей при успехе.
- **Проверено:** 10 сценариев валидатора, `make fmt`, `go build ./...`.
- **Готово:** Makefile без Postgres-целей; последовательный `make demo`.
- **Коммит:** `c47a349` — валидатор и тесты.

## D1 — API и раздача интерфейса

- **Готово:** Parquet → analysis.Run в FX OnStart до открытия HTTP-порта;
  результат в памяти, индексы входящих/исходящих рёбер.
- **Готово:** роль/кластер/компонента/top-N с соседями, карточка,
  окружение глубины 1–2, топ, кластеры, поиск по префиксу.
- **Готово:** DTO со строковыми gid, ошибки через pkg/httperr,
  шесть HTTP-эндпоинтов, регистрация FX и роутов.
- **Готово:** API/Swagger регистрируются до статики; React dist раздаётся
  Go после локальной сборки, встроенный web используется при её отсутствии.
- **Проверено:** тесты фильтров, окружения и изолированных узлов;
  API-тесты на настоящих Parquet, ответы 200/400/404 и строковые gid.
- **Проверено:** `make swag`, Swagger UI отдаёт HTTP 200 через прокси фронтенда.
- **Проверено:** pipeline/check — 2248 узлов, 3119 рёбер, 88 кластеров,
  все шесть ролей. Аналитические файлы Артёма не изменялись.
- **Коммит:** `2a82d7d` — API и резервный просмотрщик.

## D2 — React-интерфейс на реальных данных

- **Готово:** frontend/ — React + Vite + Cytoscape, компоненты App,
  GraphCanvas, NodeCard, Assistant. Зависимости фиксирует package-lock.json.
- **Готово:** стартовый топ-30 плюс соседи, резервный graph.json,
  стрелки, цвета ролей, размер по приоритету, seed-ромб, подсказки.
- **Готово:** API-поиск с подсказками, карточка, дозагрузка окружения,
  подсветка входящих/исходящих, переход к соседям, Ego 2 шага.
- **Готово:** топ с обоснованиями, фильтры, вся сеть с крупнейшей
  компонентой в фокусе, индикатор загрузки/раскладки.
- **Проверено в Chromium:**
  - старт: 478 узлов / 908 рёбер, около 3,2 секунды;
  - поиск gid `100000003115284100` и карточка: около 0,25 секунды;
  - вся сеть: 2248 узлов / 3119 рёбер, раскладка около 8,4 секунды;
  - фильтр transit: 105 узлов; кластер 0: 270 узлов;
  - перезагрузка при блокировке всех внешних сетевых запросов;
  - резервный graph.json при HTTP 503 от API;
  - явный демо-режим: 10 узлов / 12 рёбер;
  - мобильная ширина 390 px без горизонтальной прокрутки;
  - ошибок JavaScript нет.
- **Готово:** актуальный React-скриншот `docs/ui.png`.
- **Коммит:** `5417430` — React-фронтенд. Merge в main ещё не выполнен.

## D3 — инфраструктура и воспроизводимость

- **Готово:** Go Dockerfile собирает pipeline/check/web, включает data/config;
  entrypoint выполняет pipeline → check → web.
- **Готово:** frontend/Dockerfile собирает React и раздаёт через Nginx.
- **Готово:** Compose: app (:8080), frontend (:3000), healthcheck API;
  `/v1` и `/swagger` проксируются; graph.json читается из общего out.
- **Готово:** `make demo` собирает React и раздаёт его через Go на :8080;
  `npm run dev` в frontend запускает Vite на :5173 с API-прокси.
- **Готово:** README-разделы, frontend/README.md, Mermaid + docs/scheme.png.
- **Проверено:** npm build/test, go test ./..., go build ./..., make fmt.
- **Проверено:** production React через отдельный Vite preview + API-прокси.
- **Проверено:** make demo в /tmp/hackator-clean-react — около 10,1 секунды.
  Это локальный clone с наложением ещё не закоммиченных изменений; .env,
  node_modules и готовая dist не переносились. Зависимости из локального
  кэша, сетевой доступ npm выключен. Это НЕ проверка первой установки на
  совершенно чистой машине и НЕ чистый clone готового коммита.
- **Блокер Docker:** Docker Desktop сообщает, что WSL integration для этой
  системы не включена. Контейнерные сборки и запуск ещё не проверены.
- **Осталось:** Docker-прогон, настоящий clone после коммитов.

## D4 — UI для LLM

- **Готово:** справка, поле вопроса, ожидание, ссылки по gid,
  дозагрузка и подсветка узлов из ответа, скрытие при 503/404.
- **Проверено:** HTTP 503 скрывает элементы; тестовый ответ assistant
  отображается, переход по gid открывает карточку.
- **Зависимость:** сервис assistant Артёма есть, но HTTP-маршруты
  `/v1/nodes/{gid}/card` и `/v1/assistant` пока не зарегистрированы.
- **Осталось:** живая интеграция после появления этих эндпоинтов.
  Проверки выполнялись на подставных HTTP-ответах без вызовов внешнего LLM.
